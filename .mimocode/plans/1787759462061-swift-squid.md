# Plan: Add Exam Preview to Admin Dashboard

## Context
The admin dashboard top-right has a "Preview" switcher with 2 buttons: **Siswa** (→ `/dashboard`) and **Guru** (→ `/teacher`). When admin clicks one, they're taken to that dashboard with a floating "Mode Preview Admin" banner at the bottom with a "Kembali ke Admin" button. The user wants a 3rd **Exam** button that navigates to `/exam` (the new exam dashboard).

## Changes

### 1. `src/components/admin/AdminTopbar.tsx`
- Add import for `FileCheck` icon from lucide-react
- Add a 3rd preview button after "Guru":
  ```
  <button onClick={() => router.push('/exam')} ...>
    <FileCheck size={11} />
    Exam
  </button>
  ```
- Style: same pill pattern, hover color: `hover:bg-violet-50 hover:text-violet-700` (matches the exam purple theme)

### 2. `src/app/(exam)/layout.tsx`
- Import and render `<AdminPreviewBanner />` so admins see the "Kembali ke Admin" floating banner when previewing the exam dashboard
- Only renders for admin users (the component already checks `profile?.role !== 'admin'`)

## Verification
- Click "Exam" in admin topbar → navigates to `/exam`
- Floating "Mode Preview Admin" banner appears at bottom with "Kembali ke Admin"
- Click "Kembali ke Admin" → returns to `/admin`
- Siswa and Guru preview buttons still work as before
