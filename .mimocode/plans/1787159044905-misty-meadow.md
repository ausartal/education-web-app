# Ujian KPS — Implementation Plan

## Overview
Membuat platform ujian KPS (Keterampilan Proses Sains) untuk kimia kesetimbangan, berfungsi sebagai tes penempatan (placement test) seperti IELTS/TOEFL. Fitur ini **terisolasi** dari sistem education yang sudah ada, dengan akses langsung dari landing page.

## Key Decisions
- **Route group**: `(kps-ujian)` — layout terpisah dari `(dashboard)`, hanya AuthGuard tanpa navbar/sidebar
- **Akses**: Pakai kode akses (6 karakter) yang dibuat admin. Siswa harus input kode untuk memulai ujian.
- **Data**: Firestore (`kps_stimuli`, `kps_questions`, `kps_exam_sessions`, `kps_access_codes`)
- **Soal**: 7 level × 7 indikator KPS = 49 soal per set, 3 stage adaptif = 21 soal per ujian
- **Bentuk soal**: MC, Complex MC, True/False, Complex True/False, Matching
- **Jeda antar stage**: 10 menit break setelah stage 1 dan stage 2 (blank page + countdown timer)
- **Waktu strict**: Total durasi termasuk break. Timer tidak bisa di-pause. Auto-submit saat waktu habis. Tidak ada perpanjangan waktu.

## Adaptive Flow
```
Stage 1: Menengah (7 soal) → semua siswa sama
  ≥ 5/7 benar → Stage 2: Tinggi path
  < 5/7 benar → Stage 2: Rendah path

BREAK 10 MENIT (blank page + countdown timer)

Stage 2 (7 soal):
  Tinggi path + ≥ 5/7 → Stage 3: Tinggi
  Tinggi path + < 5/7 → Stage 3: Rendah
  Rendah path + ≥ 5/7 → Stage 3: Tinggi
  Rendah path + < 5/7 → Stage 3: Rendah

BREAK 10 MENIT (blank page + countdown timer)

Stage 3 (7 soal) → Final Level:
  S2=Tinggi, S3=Tinggi → Tetap Tinggi (atau Tinggi jika skor < 90)
  S2=Tinggi, S3=Rendah → Menengah Lebih Tinggi (atau Menengah)
  S2=Rendah, S3=Tinggi → Menengah Lebih Rendah (atau Menengah)
  S2=Rendah, S3=Rendah → Tetap Rendah (atau Rendah jika skor ≥ 30)
```

**Durasi Total (strict, tidak bisa di-pause):**
- Stage 1: 20 menit (soal) + 10 menit (break) = 30 menit
- Stage 2: 20 menit (soal) + 10 menit (break) = 30 menit
- Stage 3: 20 menit (soal) = 20 menit
- **Total: 80 menit** (siswa bisa mulai stage berikutnya lebih awal jika break selesai, tapi tidak bisa perpanjang)

**Strict Rules:**
- Timer global 80 menit, berjalan terus termasuk saat break
- Auto-submit semua jawaban kosong saat waktu habis
- Tidak bisa pause, rewind, atau perpanjangan waktu
- Tab-switch = warning, 3x = auto-flag
- Fullscreen wajib, keluar = blocking modal
- Tidak bisa kembali ke stage sebelumnya

**Level → Questions mapping:**
| Stage | Path | Level Used |
|-------|------|-----------|
| 1 | — | Menengah |
| 2 | Tinggi | Tinggi |
| 2 | Rendah | Rendah |
| 3 | Tinggi (dari S2=Tinggi) | Tetap Tinggi |
| 3 | Rendah (dari S2=Tinggi) | Menengah Lebih Tinggi |
| 3 | Tinggi (dari S2=Rendah) | Menengah Lebih Rendah |
| 3 | Rendah (dari S2=Rendah) | Tetap Rendah |

## Data Models (`src/types/kps.ts`)

### Core Types
```typescript
type KPSDifficultyLevel = 'tetap_rendah' | 'rendah' | 'menengah_lebih_rendah' | 'menengah' | 'menengah_lebih_tinggi' | 'tinggi' | 'tetap_tinggi';
type KPSIndicator = 'merumuskan_masalah' | 'membuat_hipotesis' | 'mengontrol_variabel' | 'merancang_investigasi' | 'mengumpulkan_mencatat_data' | 'menganalisis_menginterpretasi_data' | 'membuat_kesimpulan';
type KPSQuestionType = 'multiple_choice' | 'complex_multiple_choice' | 'true_false' | 'complex_true_false' | 'matching';
type KPSStagePath = 'tinggi' | 'rendah';
```

### Firestore Collections

**`kps_stimuli`** — Stimulus per level per stage
```
{ id, level, stage(1|2|3), title, content(markdown+katex), topic, status, createdBy, createdAt }
```

**`kps_questions`** — Soal individual (7 per stimulus)
```
{ id, stimulusId, indicator, stage, difficultyLevel, questionType, stem, explanation, order(1-7),
  status, createdBy, createdAt, usageCount, avgCorrectRate,
  // Type-specific (flat in Firestore):
  options?, correctAnswer?, correctAnswers?, partialCredit?,
  statement?, statements?(array), requireAll?,
  premises?(array), matchingOptions?(array), correctMatches? }
```

**`kps_exam_sessions`** — Session ujian siswa
```
{ id, studentId, startedAt, completedAt, durationMinutes(80), status,
  currentStage(1|2|3), stageResponses(array), stage2Path, stage3Path,
  finalLevel, numericScore(0-100), indicatorScores(map), anomalyFlags, tabSwitchCount, stimulusIds,
  accessCodeId(ref → kps_access_codes) }
```

**`kps_access_codes`** — Kode akses ujian (dibuat admin)
```
{ id, code(6 char, uppercase), createdBy(admin uid), createdAt,
  expiresAt(Timestamp), maxUses(number), currentUses(number),
  status('active' | 'expired' | 'deactivated'),
  title(string, e.g. "Ujian KPS Kelas XII - Agustus 2026"),
  description(string, optional) }
```
**Index**: `(status, expiresAt)` — for active code lookup

## API Routes

### Siswa
| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/kps/sessions/start` | POST | Mulai session baru (validasi kode akses) atau resume |
| `/api/kps/sessions/[id]/answer` | POST | Submit jawaban per soal (server-side scoring, no feedback) |
| `/api/kps/sessions/[id]/stage` | POST | Submit 7 jawaban sekaligus → trigger adaptive branching → return next stage |
| `/api/kps/sessions/[id]/complete` | POST | Selesaikan ujian → compute finalLevel, scores |
| `/api/kps/sessions/[id]` | GET | Ambil data session (untuk results page) |
| `/api/kps/history` | GET | Riwayat ujian siswa (`?limit=10&offset=0`) |

### Admin
| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/kps/admin/codes` | GET | List semua kode akses |
| `/api/kps/admin/codes` | POST | Buat kode akses baru |
| `/api/kps/admin/codes/[id]` | PATCH | Update kode (deactivate, edit) |
| `/api/kps/admin/codes/[id]` | DELETE | Hapus kode |
| `/api/kps/admin/results` | GET | Lihat hasil semua siswa |

**Security**: Semua route verifikasi Firebase Auth ID token. Admin routes verifikasi `role === 'admin'`. `answer` route fetch correctAnswer dari Firestore (client tidak pernah tahu jawaban). `stage` route re-verify semua jawaban server-side sebelum branching.

**Start Session Flow**:
1. Siswa input kode akses (6 karakter) di halaman `/ujian-kps`
2. POST `/api/kps/sessions/start` dengan `{ code: "ABC123" }`
3. Server validasi: kode exists, status=active, belum expired, currentUses < maxUses
4. Server cek: siswa belum punya session in-progress dengan kode ini
5. Jika valid: buat session, increment currentUses, return stage 1 questions
6. Jika tidak valid: return error (kode salah/expired/habis)

## Adaptive Engine (`src/lib/kps-engine.ts`)

### Functions
```typescript
// Tentukan path stage berikutnya
getNextStagePath(currentStage: 1|2|3, stage2Path: KPSStagePath|null, correctCount: number): KPSStagePath

// Mapping path → level soal yang diambil
getLevelForStagePath(stage: 1|2|3, path: KPSStagePath|null): KPSDifficultyLevel

// Scoring per tipe soal (partial credit untuk complex types)
scoreQuestion(question: KPSQuestion, answer: KPSQuestionResponse): number

// Hitung skor stage (0-100)
calculateStageScore(responses: KPSQuestionResponse[]): number

// Hitung skor per indikator across all stages
calculateIndicatorScores(allResponses: KPSQuestionResponse[]): Record<KPSIndicator, number>

// Hitung skor numerik final (0-100), weight: S1=20%, S2=30%, S3=50%
calculateNumericScore(stageResponses: KPSStageResponse[]): number

// Tentukan level final dari kombinasi path + skor
determineFinalLevel(stage2Path: KPSStagePath, stage3Path: KPSStagePath, numericScore: number): KPSDifficultyLevel
```

## Page UX Flow

### 1. Landing Page (`/ujian-kps`)
- Hero: "Ujian KPS — Tes Penempatan Keterampilan Prokses Sains"
- Info cards: 21 soal, 80 menit (termasuk break), 7 indikator, 3 tahap adaptif
- **Input kode akses** (6 karakter, uppercase) + tombol "Mulai Ujian"
- Jika ada session in-progress → "Lanjutkan Ujian" (tanpa kode)
- Link ke riwayat
- **Tanpa kode = tidak bisa mulai**. Halaman intro bisa dilihat tanpa auth, tapi "Mulai Ujian" redirect ke login jika belum auth.

### 2. Exam Session (`/ujian-kps/[sessionId]`)
- **Header**: Stage progress (1→2→3) + Timer countdown (strict, 80 menit total)
- **Body**: Stimulus di atas (shared 7 soal), soal di bawah, navigasi dots
- **Nav**: "Sebelumnya" / "Selanjutnya" + "Kumpulkan Tahap" saat semua terjawab
- **Break Screen** (antar stage): Blank page, countdown timer 10 menit, tombol "Lanjut" (bisa skip break lebih awal)
- **Anti-cheat**: Fullscreen gate, tab-switch warning (3x = flag), beforeunload, auto-submit on timeout
- **State**: localStorage (`kps_session_{id}`) untuk resume, server sebagai source of truth
- **Strict**: Timer jalan terus termasuk break. Tidak bisa kembali ke stage sebelumnya. Auto-submit kosong saat waktu habis.

### 3. Results (`/ujian-kps/[sessionId]/results`)
- Level badge besar + skor numerik
- Breakdown per stage (correct count, path)
- Radar chart 7 indikator KPS (SVG, no library)
- Detail per indikator (persentase + label)
- Tombol: Riwayat, Ulangi (perlu kode baru), Dashboard

### 4. Riwayat (`/ujian-kps/riwayat`)
- List session selesai (newest first)
- Card: tanggal, level badge, skor, correct count
- Click → expand indicator breakdown

### 5. Admin Dashboard (`/admin/kps`)
- Overview: total ujian, rata-rata skor, distribusi level
- **Kode Akses** (`/admin/kps/codes`):
  - List kode (tabel): kode, judul, status, sisa kuota, expired, jumlah dipakai
  - Tombol "Buat Kode Baru": modal form (judul, deskripsi, kuota, tanggal expired)
  - Copy kode ke clipboard, deactivate, delete
- **Hasil Siswa** (`/admin/kps/results`):
  - Tabel: nama siswa, tanggal, level, skor, detail (expand)
  - Filter: per kode akses, per tanggal, per level

## Firestore Rules Addition
```
match /kps_stimuli/{docId} {
  allow read: if isAuth();
  allow write: if false; // Admin SDK only
}
match /kps_questions/{docId} {
  allow read: if isAuth();
  allow write: if false; // Admin SDK only
}
match /kps_exam_sessions/{docId} {
  allow read: if isAuth() && resource.data.studentId == uid();
  allow create, update: if false; // Admin SDK only
}
match /kps_access_codes/{docId} {
  allow read: if isAdmin();
  allow write: if false; // Admin SDK only
}
```

## Verification Plan
1. **Unit test**: `kps-engine.ts` — test semua scoring function dan adaptive branching logic
2. **Admin flow test**:
   - Login sebagai admin → buka `/admin/kps/codes`
   - Buat kode akses baru (judul, kuota, expired)
   - Copy kode, verify muncul di list
   - Deactivate kode, verify status berubah
3. **Student flow test**:
   - Buka landing page → klik "Ujian KPS" → lihat intro page
   - Input kode akses → klik "Mulai Ujian" → redirect ke login jika belum auth
   - Login → mulai ujian → jawab 7 soal stage 1
   - Klik "Kumpulkan Tahap" → verify break screen 10 menit muncul
   - Skip break atau tunggu → verify stage 2 load dengan path yang benar
   - Jawab stage 2 → break → stage 3 → selesai
   - Verify results page: level badge, skor, radar chart, indicator scores
   - Check riwayat page → verify session muncul
4. **Strict timing test**:
   - Verify timer jalan terus selama break
   - Verify auto-submit saat waktu habis
   - Verify tab-switch warning (3x = flag)
   - Verify fullscreen gate
5. **Edge cases**: Kode expired, kode habis kuota, resume dari localStorage, connection drop mid-exam
6. **Security**: Verify client tidak bisa akses correctAnswer, server-side scoring konsisten, admin-only routes terproteksi
