# UKKBI — Uji Kompetensi Kimia Berbasis Indikator (Pelengkap KPS)

## Overview
UKKBI adalah layer hasil/credential untuk fitur KPS yang sudah ada. Setelah siswa menyelesaikan ujian KPS, mereka mendapat UKKBI Score Report komprehensif — mirip Test Report Form (TRF) IELTS. UKKBI bukan platform terpisah, tapi bagian dari halaman KPS yang menampilkan hasil, riwayat, kredensial, dan rekomendasi belajar.

## Scope yang Dibangun

### 1. Dashboard UKKBI (Overview)
- Welcome + Candidate Name
- Current Proficiency Level (badge, bukan besar — kecil di card)
- Latest Overall Score + Score Validity
- Score Trend (sparkline/mini chart)
- Quick Actions (View Scores, Download Certificate, Test History)
- Test Announcements / Upcoming Tests

### 2. Score Reports
- Overall Score Report (komprehensif)
- Section Scores (per indikator KPS — 7 indikator)
- Competency Breakdown (detail per soal)
- Percentile Rank (National, Institutional, Global)
- Test Date, Test ID, Score Validity, Test Status
- Download PDF, Print Score Report

### 3. Test History
- Riwayat seluruh ujian KPS
- Nama ujian, Tanggal, Test ID, Score, Level, Status, Validity
- Best Score vs Latest Score
- Score Progression chart

### 4. Credentials
- Download Certificate (PDF)
- Certificate Number, Issue Date, Expiration Date
- (Email delivery — next update)

### 5. My Learning (Preparation)
- Recommended Assessment berdasarkan weak areas
- Weak Competencies analysis
- Suggested Materials
- Practice Test links

### 6. Info
- Test Announcements
- Examination Schedule
- Policy / Regulations

## Data Model

### Firestore Collections (existing + new)

**`kps_exam_sessions`** (sudah ada) — tambah field:
```
+ testId: string (auto-generated, e.g. "KPS-2026-00001")
+ validity: { start: Timestamp, end: Timestamp } (1 tahun)
+ percentile: { national: number, institutional: number, global: number }
+ sectionScores: Record<KPSIndicator, { score: number, level: string, correct: number, total: number }>
+ status: 'completed' | 'flagged' | 'expired' | 'revoked'
```

**`kps_certificates`** (NEW):
```
{ id, studentId, sessionId, testId, certificateNumber,
  issuedAt, expiresAt, status: 'active' | 'expired' | 'revoked',
  pdfUrl: string | null }
```

**`kps_announcements`** (NEW):
```
{ id, title, content, type: 'announcement' | 'schedule' | 'policy',
  publishedAt, expiresAt, status: 'active' | 'archived' }
```
