# Fix: KPS Stage Submit Bug — "Diperlukan 7 jawaban untuk stage 1"

## Root Cause Analysis

Error "Diperlukan 7 jawaban untuk stage 1" muncul saat user submit stage 1. Kemungkinan penyebab:

### 1. Questions array kosong saat submit
Exam page load questions dari `sessionStorage` (`exam_init_{sessionId}`). Jika data tidak tersimpan dengan benar atau questions kosong, `questions.map()` menghasilkan array kosong → server terima 0 responses.

### 2. Question ID mismatch
Client-side `answers` state menggunakan `question.id` sebagai key. Jika ID dari Firestore berbeda dengan yang di-render, `answers[q.id]` akan undefined.

### 3. Race condition antara init dan submit
User bisa klik "Kumpulkan Tahap" sebelum questions ter-load sepenuhnya.

## Fix Plan

### File: `src/app/(kps-ujian)/ujian-kps/[sessionId]/page.tsx`

1. **Tambah guard di handleSubmitStage**: cek `questions.length === 7` sebelum submit
2. **Tambah loading state** saat questions belum ter-load
3. **Log questions length** untuk debugging
4. **Tambah retry** jika questions kosong

### File: `src/app/api/kps/sessions/start/route.ts`

1. **Validasi questions.length** sebelum return response
2. **Return error** jika soal tidak cukup

### File: `src/app/api/kps/sessions/[id]/stage/route.ts`

1. **Tambah logging** untuk debug: log rawResponses.length, questions IDs
2. **Error message lebih spesifik**: tampilkan actual count vs expected
