# Security Audit — AKURAT Education Web App

## Summary

Audit keamanan untuk web app quiz AKURAT. Ditemukan **3 critical**, **1 high**, dan **3 medium** vulnerabilities.

---

## Critical Issues

### 1. Custom/Manual Exam: Server trusts client-sent `isCorrect` (CRITICAL)
**File**: `src/app/api/exam-sessions/[id]/complete/route.ts:51-56`

```typescript
const customAnswers = (body2.customAnswers ?? []) as Array<{...; isCorrect: boolean; ...}>;
const correctCount = customAnswers.filter(a => a.isCorrect).length;
```

**Masalah**: Server menerima `isCorrect` dari client tanpa verifikasi. Siswa bisa mengirim `isCorrect: true` untuk semua jawaban dan mendapat skor 100%.

**Fix**: Hitung `isCorrect` di server dengan membandingkan `selectedAnswer` dengan `correctAnswer` dari `scheduleData.customQuestions`.

---

### 2. Latihan Quiz: `correctAnswer` exposed di client (CRITICAL)
**File**: `src/app/(dashboard)/latihan/[quizId]/page.tsx:77,181,242`

**Masalah**: Soal latihan di-fetch langsung dari Firestore client SDK (`services/questions.ts`), dan `Question` interface includes `correctAnswer`. Siswa bisa melihat jawaban benar via browser DevTools (Network tab atau React DevTools).

**Fix**: Buat API route server-side yang menghapus `correctAnswer` sebelum mengirim ke client. Atau gunakan Firestore rules untuk membatasi field yang bisa dibaca.

---

### 3. Custom Exam Questions: `correctAnswer` dikirim ke client (CRITICAL)
**File**: `src/app/api/exam-sessions/start/route.ts:108-112`

```typescript
return NextResponse.json({
  sessionId: docRef.id, mode,
  schedule: schedulePayload, customQuestions,  // ← includes correctAnswer
  resumed: false,
});
```

**Masalah**: Untuk custom/manual exam, `customQuestions` (termasuk `correctAnswer`) dikirim ke client saat memulai sesi. Siswa bisa inspect response dan melihat semua jawaban.

**Fix**: Strip `correctAnswer` dari `customQuestions` sebelum dikirim ke client.

---

## High Issues

### 4. Middleware tidak melindungi route admin/teacher (HIGH)
**File**: `src/middleware.ts:11-13`

```typescript
if (pathname.startsWith('/api/')) {
  return NextResponse.next();
}
```

**Masalah**: Semua API routes dipass-through tanpa pengecekan di middleware. Meskipun API routes punya auth sendiri, beberapa route mungkin terlewat. Middleware seharusnya jadi lapisan pertahanan kedua.

**Fix**: Tambahkan pengecekan token di middleware untuk route `/api/admin/*` dan `/api/teacher/*`.

---

### 5. ~~Exam session domain route tidak ada auth check~~ (VERIFIED SAFE)
**File**: `src/app/api/exam-sessions/[id]/domain/route.ts`

Route ini sudah aman:
- Memeriksa auth token (line 10-16)
- Memeriksa ownership: `session.studentId !== decoded.uid` (line 23)
- **Recompute `isCorrect` server-side** (line 49-56) — tidak trust client
- Validasi adaptive branch paths (line 66-80)

## Medium Issues

### 6. Question Bank: Firestore rules terlalu permisif untuk siswa (MEDIUM)
**File**: `firestore.rules:46`

```
allow read: if isAuth();
```

**Masalah**: Semua user yang terautentikasi (termasuk siswa) bisa membaca `question_bank` yang mungkin termasuk `correctAnswer`.

**Fix**: Batasi read access ke `isTeacherOrAdmin()` atau buat field-level security.

---

### 7. Exam Questions: Firestore rules terlalu permisif (MEDIUM)
**File**: `firestore.rules:130`

```
allow read: if isTeacherOrAdmin();
```

Ini sudah benar untuk `exam_questions`. Tapi perlu dipastikan tidak ada client code yang bypass API dan langsung fetch dari Firestore.

---

### 8. Tidak ada rate limiting pada API routes (MEDIUM)
**File**: Semua API routes

**Masalah**: Tidak ada rate limiting, memungkinkan brute force attack pada exam token atau spam requests.

**Fix**: Tambahkan rate limiting middleware atau gunakan Firebase App Check.

---

## Safe Patterns (Sudah Benar)

- **MSAT Exam**: Jawaban dicek server-side via `/api/exam-sessions/[id]/check-answer` (line 37: `isCorrect = selectedAnswer === qData.correctAnswer`)
- **Score calculation**: Dilakukan server-side di `/complete` route
- **Time validation**: Server-side time check dengan 5 menit grace period
- **Auth helpers**: `verifyAdmin`, `verifyTeacher`, `verifyStudent` properly implemented
- **Firestore rules**: Exam sessions hanya bisa dibuat/diupdate via Admin SDK (`allow create: if false; allow update: if false;`)
- **Audit logs**: Semua aksi penting dicatat
- **Anti-cheat**: Tab switching detection, fullscreen requirement
- **Env config**: Hanya public keys di `.env.example`, service account di `.env.local`

### Fix 3 (CRITICAL): Buat API route untuk latihan questions tanpa correctAnswer
**File baru**: `src/app/api/practice-questions/route.ts`

Buat API route yang fetch dari Firestore dan strip `correctAnswer` sebelum return:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import { adminDb } from '@/lib/firebase-admin';
import { verifyStudent } from '@/lib/auth-helpers';

export async function GET(req: NextRequest) {
  const user = await verifyStudent(req);
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });

  const { searchParams } = new URL(req.url);
  const topic = searchParams.get('topic');
  const difficulty = searchParams.get('difficulty');
  const count = parseInt(searchParams.get('count') || '10');

  if (!topic || !difficulty) {
    return NextResponse.json({ error: 'topic and difficulty required' }, { status: 400 });
  }

  const q = adminDb.collection('question_bank')
    .where('topic', '==', topic)
    .where('difficulty', '==', difficulty)
    .where('status', '==', 'active')
    .limit(count);

  const snap = await q.get();
  const questions = snap.docs.map(d => {
    const { correctAnswer, misconceptions, ...rest } = d.data();
    return { id: d.id, ...rest };
  });

  return NextResponse.json({ questions });
}
```

### Fix 4 (HIGH): Middleware API route protection
**File**: `src/middleware.ts`

Tambahkan pengecekan token untuk admin/teacher routes:

```typescript
import { NextRequest, NextResponse } from 'next/server';

const AUTH_ROUTES = ['/login', '/register', '/forgot-password'];

export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // API routes handle their own auth via Bearer token
  if (pathname.startsWith('/api/')) {
    return NextResponse.next();
  }

  // Page-level guards are handled by AuthGuard + RoleGuard components
  const isAuthRoute = AUTH_ROUTES.some(r => pathname.startsWith(r));
  void isAuthRoute;

  return NextResponse.next();
}

export const config = {
  matcher: ['/admin/:path*', '/api/admin/:path*', '/teacher/:path*'],
};
```

Catatan: Middleware saat ini sudah tidak memblok API routes (by design, karena Firebase SDK pakai localStorage bukan cookies). Ini adalah pattern yang benar untuk Firebase + Next.js. Tidak perlu diubah.

### Fix 6 (MEDIUM): Rate limiting (opsional)
**File**: `src/middleware.ts` atau package `next-rate-limit`

Tambahkan rate limiting untuk API routes sensitif:
- `/api/exam-sessions/start` — max 10 requests/minute per user
- `/api/exam-sessions/[id]/check-answer` — max 100 requests/minute per user
- `/api/exam-sessions/[id]/complete` — max 5 requests/minute per user

Ini bisa diimplementasi dengan package `next-rate-limit` atau custom middleware.
